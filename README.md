# astrbot_plugin_sticker

让 AstrBot 里的角色**说话像人**：把多行回复合并成一条、按情绪发本地表情包、偶尔发一条语音。

写给"想让她看起来像个真人"的场景，所有能调的东西都在插件配置里，代码里没有写死的路径。

## 功能

| 功能 | 说明 |
|---|---|
| **多行合并** | 模型输出多行时，按字数合并成 1 条或拆成 2 条，避免"一句话刷三条" |
| **表情包** | 模型输出 `[[表情:开心]]` → 删掉标记，从 `表情包/开心/` 随机取一张附在后面 |
| **表情包冷却** | 每 N 条回复最多附 1 张 |
| **语音** | 每 N 条回复抽一条，调本地 GPT-SoVITS 合成语音条 |
| **语音后处理** | 可选降调、放慢、加首尾留白（避免突然开始/结束） |
| **AI 腔过滤** | 代码层删掉"我理解你的感受""希望能帮到你""慢慢来"这类客服句式，不靠提示词自觉 |

## 安装

1. 把整个目录放进 `AstrBot/data/plugins/`
2. 重启 AstrBot
3. 打开插件配置，填下面几项

## 配置

| 键 | 必填 | 说明 |
|---|---|---|
| `sticker_root` | 否 | 表情包根目录。默认 `<插件>/data/stickers`。**目录结构见下** |
| `sticker_fallback_dir` | 否 | 总库目录名，分类没图时从这里随机取，默认 `表情包库` |
| `tts_url` | 否 | GPT-SoVITS 的 `/tts` 地址，例如 `http://127.0.0.1:9880/tts`。留空 = 不语音 |
| `voice_ref` | 否 | 参考音频路径（3~10 秒清晰人声） |
| `voice_prompt` | 否 | 参考音频的文字稿（填了韵律更稳） |
| `voice_dir` | 否 | 合成临时目录，默认 `<插件>/data/voice` |
| `ffmpeg_path` | 否 | ffmpeg 可执行文件；留空用 PATH 里的 |

其余是冷却、字数区间、音高、语速、留白、合并阈值，都有默认值。

### 表情包目录结构

```
<sticker_root>/
├── 开心/      1.jpg  2.png ...
├── 害羞/
├── 生气/
├── 委屈/
├── 无语/
├── 亲亲/
├── 困/
└── 表情包库/   未分类的原图，分类为空时从这里兜底
```

分类名固定为上面那 7 个（`LABELS`）；要改分类，改 `main.py` 里的 `LABELS` 和 `_conf_schema.json`。

## 命令

| 命令 | 作用 |
|---|---|
| `/表情 开心` | 直接发一张 |
| `/表情列表` | 看每个分类有多少张 |
| `/存表情 开心` | 引用一张图发这条，存进该分类 |
| `/语音 在呀鱼宝` | 手动合成一条，不用等冷却 |

## 接 GPT-SoVITS

本插件只负责调用，不包含 TTS 引擎。你需要本地或局域网跑一个 GPT-SoVITS 的 `api_v2.py`：

```bash
python api_v2.py -a 127.0.0.1 -p 9880 -c GPT_SoVITS/configs/tts_infer.yaml
```

然后 `tts_url` 填 `http://127.0.0.1:9880/tts`。

语音后处理依赖 ffmpeg，Windows 可以直接用 imageio-ffmpeg 自带的二进制，把 `ffmpeg_path` 指过去。

## 合并规则

- 多行总字数 ≤ `one_message_limit`（默认 26）→ 合并成一条，用「，」连接
- 超过 → 按字数切成 `max_parts` 条（默认 2）
- 单条超过 14 字且含逗号 → 再拆一次（让语气更像逐条发的短句）

## 已知限制

- 语音和表情包互斥：这一条发了语音就不附图
- AI 腔词表是启发式的，遇到漏网的把原句加到 `AI_SPEAK` 里
